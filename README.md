## 📋 Instructions

### 1. Clone the Repository
```bash
git clone git@github.com:TormodMasdal/CarRental.git
cd 103-Exam
```

---

### 2. CLion Setup
- Open **CLion** and select **"Open"** from the welcome screen.
- Navigate to the cloned repository and select it.
- CLion will automatically detect the **CMakeLists.txt** file and configure the project.
- If prompted, choose to use the **bundled CMake and compiler**.
- Enable **VCPKG** and edit **VCPKG** to add the current **CMake Profile**.
- Reload the **CMake project** if errors appear in the log.
- Set the working directory to the **project root directory**.
- Once the project is configured correctly, you can **build and run it directly** from CLion.

---

### 3. Git Workflow
- Use CLion's **built-in Git support** to manage your repository.
- **Commit your changes regularly** and push them to the remote repository.
- Always **pull the latest changes** from the remote repository before starting new work.
- If you encounter conflicts:
    - **Shelve your changes**,
    - Pull the latest changes,
    - Then **reapply your shelved changes**.
